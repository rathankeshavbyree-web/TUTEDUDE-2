# Indian Laundry Wallah

This is a simple laundry service website created using HTML. The purpose of this project is to practice basic HTML concepts such as headings, paragraphs, images, lists, tables, forms, and links.

The website is designed for a fictional laundry business called "Indian Laundry Wallah." It provides information about the services offered, a small price list, and a booking form where customers can enter their details to request a service.

## Features

- Welcome section with a short introduction
- Laundry service image
- List of services provided
- Price table for selected services
- Booking form with Name, Email, and Phone fields
- Contact email link

## Technologies Used

- HTML5

## Project Files

- `index.html` – Main webpage
- `laundry.jpg` – Image used on the website
- `README.md` – Project description

## How to Use

1. Download or copy all project files into a single folder.
2. Place the image file and name it `laundry.jpg`.
3. Open `index.html` in any web browser.
